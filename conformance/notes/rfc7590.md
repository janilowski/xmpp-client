# RFC 7590: review notes

Migrated from the 2026-07-29 inventory. These are **unverified review notes**,
not a complete extraction or a compliance claim. Preserve IDs when adding tests;
check the original clause, its conditions and errata before implementation.
Executable coverage belongs in the standard's suite and coverage map, not here.

## RFC7590-follow-bcp195

RFC 7590 §1 and 3; MUST; both; responsibility: shared.

When: Whenever TLS protects XMPP

Follow the current BCP 195 recommendations rather than the obsolete TLS profile originally named by RFC 7590.

Scope: delegated. The browser implements TLS, while the library and deployment choose secure transports and endpoints.

## RFC7590-attempt-unadvertised-starttls

RFC 7590 §3.1; MUST NOT; client; responsibility: library.

When: When a TCP XMPP server does not advertise STARTTLS

Do not let absence of the STARTTLS feature alone deter a TLS attempt.

Scope: replaced. RFC 7395 negotiates TLS at the WebSocket layer before XMPP and forbids XMPP-layer STARTTLS.

## RFC7590-local-policy-starttls

RFC 7590 §3.1; SHOULD; client; responsibility: library.

When: When local policy permits connection and a TCP server omits STARTTLS

Attempt STARTTLS despite the missing advertisement.

Scope: replaced. The target profile uses WSS instead of XMPP-layer STARTTLS.

## RFC7590-session-resumption

RFC 7590 §3.3; MUST; both; responsibility: browser.

When: When TLS session resumption is used

Follow current BCP 195 session-resumption security requirements.

Scope: delegated. Browser WebSocket APIs control TLS session resumption.

## RFC7590-client-authenticates-server

RFC 7590 §3.4; MUST; client; responsibility: shared.

When: For every TLS-protected XMPP connection

Authenticate the server rather than accepting an unauthenticated TLS connection.

Scope: delegated. The browser validates the WSS endpoint; secure XMPP-domain delegation remains library behavior.

## RFC7590-server-authenticates-client

RFC 7590 §3.4; MUST; server; responsibility: server.

When: For a client connection

Authenticate the client.

Scope: not-applicable. Server-side authentication policy.

## RFC7590-server-authenticates-peer

RFC 7590 §3.4; SHOULD; server; responsibility: server.

When: For a server-to-server connection

Authenticate the peer server.

Scope: not-applicable. Server-to-server behavior is outside the client profile.
