# XEP-0156 1.4.0: review notes

Migrated from the 2026-07-29 inventory. These are **unverified review notes**,
not a complete extraction or a compliance claim. Preserve IDs when adding tests;
check the original clause, its conditions and errata before implementation.
Executable coverage belongs in the standard's suite and coverage map, not here.

## XEP0156-fetch-host-meta-https

XEP-0156 1.4.0 §2.2 and 4; MUST; client; responsibility: shared.

When: When retrieving host-meta for connection discovery

Fetch host-meta only over HTTPS.

Scope: delegated. The library constructs the HTTPS URL and the browser performs TLS.

## XEP0156-secure-connection-urls

XEP-0156 1.4.0 §2.2 and 4; MUST; client; responsibility: library.

When: When consuming a discovered connection URL

Use only https or wss connection URLs.

## XEP0156-delegated-certificate-validation

XEP-0156 1.4.0 §2.2; SHOULD; client; responsibility: browser.

When: When a discovered endpoint host differs from the XMPP domain

Send SNI for the endpoint host and validate the certificate for that host or the XMPP domain.

Scope: delegated. The browser controls SNI and certificate validation for fetch and WebSocket connections.

## XEP0156-server-offer-xrd

XEP-0156 1.4.0 §2.2; MUST; server; responsibility: server.

When: When publishing alternative connection information

Offer an XRD host-meta representation.

Scope: not-applicable. Server publication behavior.

## XEP0156-server-offer-jrd

XEP-0156 1.4.0 §2.2; SHOULD; server; responsibility: server.

When: When publishing alternative connection information

Also offer a JRD host-meta representation.

Scope: not-applicable. Server publication behavior; client parsing coverage is tracked as a dependency of discovery interoperability.

## XEP0156-http-after-rfc6120

XEP-0156 1.4.0 §2.2; MUST; client; responsibility: library.

When: When both RFC 6120 DNS discovery and HTTP host-meta are available

Use HTTP host-meta only after the RFC 6120 methods are exhausted.

Scope: replaced. RFC 7395 section 4 defines host-meta as the browser-compatible alternative because browser clients cannot perform the RFC 6120 DNS procedure.

## XEP0156-server-no-duplicate-srv

XEP-0156 1.4.0 §2.2; SHOULD NOT; server; responsibility: server.

When: When publishing host-meta link records

Do not duplicate connection information already available through RFC 6120 DNS SRV records.

Scope: not-applicable. Server publication behavior.

## XEP0156-link-order-insignificant

XEP-0156 1.4.0 §2.2; SHOULD NOT; both; responsibility: library.

When: When publishing or consuming multiple XMPP host-meta links

Do not interpret document order as preference or priority.

## XEP0156-server-cors

XEP-0156 1.4.0 §3; SHOULD; server; responsibility: server.

When: When host-meta is intended for cross-origin web clients

Set appropriate CORS response headers.

Scope: not-applicable. Server HTTP configuration.
