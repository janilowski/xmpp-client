## BCP195-no-ssl2

BCP 195 / RFC 9325 §3.1.1; MUST NOT; both; responsibility: browser.

When: During TLS negotiation

Do not negotiate SSL 2.0.

Scope: delegated. The browser TLS stack controls protocol negotiation.

## BCP195-support-tls13

BCP 195 / RFC 9325 §3.1.1; SHOULD; both; responsibility: browser.

When: For an existing TLS-based application protocol

Support TLS 1.3 and prefer it over earlier versions when supported.

Scope: delegated. The browser TLS stack controls supported and preferred protocol versions.

## BCP195-no-version-fallback

BCP 195 / RFC 9325 §3.1.3; MUST NOT; client; responsibility: browser.

When: After a TLS 1.2 or newer negotiation failure

Do not fall back to a TLS version below 1.2.

Scope: delegated. The browser TLS stack controls version fallback.

## BCP195-prefer-tls-only-transport

BCP 195 / RFC 9325 §3.2; MUST; both; responsibility: shared.

When: When a protocol offers both TLS-only and dynamic STARTTLS transports

Support and prefer the TLS-only transport.

## BCP195-no-tls-compression

BCP 195 / RFC 9325 §3.3; SHOULD NOT; both; responsibility: browser.

When: When TLS 1.2 is negotiated

Do not enable TLS-level compression.

Scope: delegated. The browser TLS stack controls TLS compression.

## BCP195-secure-renegotiation

BCP 195 / RFC 9325 §3.5; MUST; client; responsibility: browser.

When: When TLS 1.2 is negotiated

Require secure renegotiation and extended master secret support.

Scope: delegated. The browser TLS stack controls TLS extensions and handshake failure.

## BCP195-sni-support

BCP 195 / RFC 9325 §3.7; MUST; client; responsibility: browser.

When: For HTTPS and WSS connections that benefit from virtual hosting

Support Server Name Indication.

Scope: delegated. The browser derives and sends SNI from the endpoint URL.

## BCP195-abort-hostname-mismatch

BCP 195 / RFC 9325 §3.7 and 6; SHOULD; client; responsibility: browser.

When: When the server certificate does not match the requested endpoint hostname

Abort the TLS connection.

Scope: delegated. The browser performs WSS and HTTPS hostname validation.

## BCP195-no-rc4

BCP 195 / RFC 9325 §4; MUST NOT; both; responsibility: browser.

When: When selecting TLS cipher suites

Do not negotiate RC4 cipher suites.

Scope: delegated. The browser TLS stack controls cipher suites.

## BCP195-aead-ciphers

BCP 195 / RFC 9325 §4; SHOULD; both; responsibility: browser.

When: When selecting TLS cipher suites

Prefer authenticated-encryption cipher suites with forward secrecy.

Scope: delegated. The browser TLS stack controls cipher-suite selection.

## BCP195-new-protocol-tls13

BCP 195 / RFC 9852 §3; MUST; both; responsibility: deployment.

When: When defining a new protocol that uses TLS

Require TLS 1.3.

Scope: not-applicable. XMPP and its RFC 7395 WebSocket binding predate RFC 9852 and are existing protocols, not a new protocol definition.
