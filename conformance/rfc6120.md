claims of full coverage of those extensions. Unit cases use controlled pauses
to expose interleavings; wire cases use actual WebSocket connections.

## Local policy and boundaries

Negotiation exchanges use `entity.timeout` (the existing connection timeout,
default 2000 ms). IQ retains its 30-second default; resource binding uses the
negotiation deadline. These durations are local policy, not RFC requirements.
Responses, send/handler failures, close, disconnect and expiry release owned
listeners and timers. A deadline starts before sending, including a stalled send.

Cancellation is cooperative: arbitrary application callbacks cannot be forcibly
stopped. Once they settle, library checkpoints prevent further protocol work;
the library does not undo external side effects already performed by callbacks.

## IQ reply identities (#11)

ID and sender must both match before a result resolves or an error rejects an
exchange. Sender correlation is a local security policy derived from the RFC's
addressing and request/reply rules, not a verbatim RFC matching algorithm.

| Request destination                    | Accepted reply sender                                 |
| -------------------------------------- | ----------------------------------------------------- |
| Full JID                               | Same full JID, including case-sensitive resource      |
| Bare JID                               | Same bare JID, optionally with a resource             |
| No `to`                                | No `from`, negotiated server domain, or own bare JID  |
| Own bare JID or explicit server domain | Also accepts absent `from` for server/account replies |

An absent `from` never authenticates a reply to a remote target. An intermediate
error retains the intended recipient in `from`; `error@by` names the generator
(§8.3.1) and does not override sender validation. Other resources of one's own
account cannot answer a no-`to` server request.

Evidence: [wire regressions](rfc6120.test.ts) reproduce forged results and errors
before an authentic response; [identity matrix](../src/iq/test/senders.test.js)
covers bare/full/server addressing, resource case, unrelated and empty senders,
duplicate active IDs, ID reuse, request snapshots, timeout and disconnect.
[Existing IQ tests](../src/iq/test/caller.test.js) cover send failures and stale
session replies. Removing sender validation is detected by an assertion in the
[mutation gate](mutations.ts), not merely a crash or timeout.

Active duplicate IDs reject before sending without replacing the first request.
Caller-supplied IDs reused for the same peer cannot distinguish delayed old
responses; callers should use fresh IDs (the default generates them).

Matching now uses the [RFC 7622 preparation boundary](rfc7622.md), including
PRECIS/IDNA equivalence. Malformed incoming identities do not enter middleware
or resolve pending exchanges; raw stanza events remain untrusted observations.
